# MTN CUSTOMER CHURN ANALYSIS

##  PROJECT OVERVIEW
  This project analyzes customer churn patterns for MTN using Power Bi. The dashboard provides insights into customer churn,
  churn reasons,customer satisfaction,revenue,states, MTN devices.
  

##  OBJECTIVES
- Analyze the overall customer churn rate.
- Identify the major reasons customers leave.
- identify states with the highest number of churned customers.
- Analyze churn across different MTN devices.
- Understand customer satisfaction levels.
- Provide insights that can support customer retention strategies.


## KEY FINDINGS
- Total customers/rows analyzed: 974
- Churned customers: 284
- Churn rate: 29.16%
- Total revenue: 199M
- Average satisfaction rate: 2.95/5
 

## TOOLS USED
- Power Bi
- Power Query
- DAX
- Github
 

 ## RECOMMENDATIONS
- Address high call tariffs and pricing concerns
- Improve network quality and reliability.
- Review data plan pricing and customer value.
- Improve customer service.
- Develop targeted retention strategies for customers at high risk of churning.
 

##  CONCLUSION
The analysis provides useful insights into customer churn patterns and highlights key areas MTN  can focus on to improve 
customer satisfaction and retention.
